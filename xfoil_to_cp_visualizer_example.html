XFOIL → cp_visualizer: one complete test run

Example case: E423 airfoil, Re = 900,000, Mach 0.1, α = 12°, 34 m/s, ribs 3 in apart and 1/8 in thick. Change the numbers to fit your own case.

e423.dat→XFOIL→e423_a12.cp→ cp_visualizer.py→.png + .csv loads

0. Before you start

  1. Put e423.dat, cp_visualizer.py and nothing else important in one folder.
  2. Open a terminal and cd into that folder. XFOIL reads and writes files in the folder it was started from.
  3. Install the Python packages once:
terminal
python3 -m pip install numpy matplotlib

1. Run XFOIL

Option A: type the commands interactively

Start XFOIL, then type each line at its prompt. A line shown as (Enter) means press Enter on an empty line.

terminal → XFOIL prompts
xfoil
LOAD e423.dat          # read the airfoil coordinates
OPER                   # enter the analysis menu
VISC 9e5               # viscous mode, Reynolds number 900,000
MACH 0.1               # Mach number (about 34 m/s at sea level)
ITER 200               # allow more iterations so the solution converges
ALFA 12                # solve at angle of attack 12 degrees
CPWR e423_a12.cp       # write x and Cp for every surface point
DUMP e423_a12.dmp      # optional: boundary layer data (Cf, shear)
(Enter)                # leave OPER
QUIT                   # exit XFOIL

The # comments are for you to read here. Don't type them into XFOIL.

Check the result before moving on. After ALFA 12, XFOIL prints CL, CM and CD. Write CL down (you'll compare it with the visualizer's output). If it prints VISCAL: Convergence failed, type INIT and run ALFA 12 again.

Option B: run the same steps from a script file

Save the block below as e423_a12_xfoil.txt in the same folder. This version has no comments, because XFOIL would try to run them as commands. The blank line before QUIT is required: it is the "Enter" that leaves the OPER menu.

e423_a12_xfoil.txt
PLOP
G

LOAD e423.dat
OPER
VISC 9e5
MACH 0.1
ITER 200
ALFA 12
CPWR e423_a12.cp
DUMP e423_a12.dmp

QUIT

The first three lines (PLOP, G, blank line) turn off XFOIL's plot window so the script runs without popping one up. Then run:

terminal
xfoil < e423_a12_xfoil.txt

If a file named e423_a12.cp already exists, XFOIL asks whether to overwrite it, and the script can stall or skip the write. Delete old output files before re-running the script.

Don't use PANE here unless you also save the result. PANE re-spaces the airfoil points, so the .cp file no longer lines up point-for-point with e423.dat. The visualizer will still work (it interpolates and warns you), but for an exact match, add SAVE e423_paneled.dat right after PANE and give the visualizer that file instead.

2. Run the visualizer

terminal
python3 cp_visualizer.py e423.dat e423_a12.cp --V 34 --spacing 3 --thickness 0.125 \
        --buckets 6 --bucket-spacing adaptive --alpha 12 --save out/e423_a12
PieceWhat it does
e423.datAirfoil shape: the same file XFOIL loaded
e423_a12.cpPressure data XFOIL just wrote
--V 34Airspeed in m/s, gives dynamic pressure q = ½ρV² ≈ 708 Pa
--spacing 3 --thickness 0.125Rib spacing and thickness (same unit), gives K = 3 / 0.125 = 24
--buckets 6Average the pressure over 6 sections per surface
--bucket-spacing adaptiveShort sections where pressure changes fast (the nose), long ones elsewhere
--alpha 12Must equal the ALFA you ran in XFOIL; used to report CL for comparison
--save out/e423_a12Writes the plot and two CSV files into a folder named out
\Continues the command on the next line (macOS/Linux). You can also write it on one line.

Optional additions: --load-factor 4 for a 4 g pull-up, --chord 0.3 for lengths in meters, --upper-x-edges 0.05 0.2 0.5 to match splines you already drew.

3. What you get

FileContents
out/e423_a12.pngPressure arrows on the airfoil, the averaged sections, and Cp vs x
out/e423_a12_buckets.csvOne row per section: start/end points (spline break points) and average pressure in Pa and psi, ready to enter as FEA pressure loads
out/e423_a12_points.csvCp, pressure and surface normal at every point

4. Check that it worked

  1. The terminal shows [ OK ] Point-for-point match. (If it says the Cp values were interpolated instead, see the PANE note above.)
  2. The Cl the visualizer prints is close to the CL XFOIL printed (within a few percent; the visualizer leaves out skin friction).
  3. No Trailing-edge Cp warning. That warning means the flow is stalled and the loads are unreliable.
  4. The conservation check shows small differences (a few percent). If not, add buckets or use custom edges.

5. Run another angle

Change 12 in three places: ALFA, the two XFOIL output file names, and --alpha plus the file names in the visualizer command. For example, for 8°:

terminal
python3 cp_visualizer.py e423.dat e423_a8.cp --V 34 --spacing 3 --thickness 0.125 \
        --buckets 6 --bucket-spacing adaptive --alpha 8 --save out/e423_a8
